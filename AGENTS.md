# Instructions for AI agents and bots

The full instructions are in [CLAUDE.md](CLAUDE.md). Read it before making any change.

The most important rule: **after every change, run the tests, update the docs (`README.md`, `docs/`, and the
changelog in `docs/CHANGELOG.md`), then commit and push to git (`git push origin main`).** A change isn't finished
until it's documented and pushed.
